# 📖 How to Use the Booking Chatbot

Follow the steps below to book a bus ticket using the AI chatbot.

### Step 1: Launch the Application
Run the application using Google Colab or Gradio.

### Step 2: Start the Chat
The chatbot displays a welcome message and the main menu.

Example:

```text
Welcome to Pradeep Tamilnadu Travels

1. Book Ticket
2. Bus Timings
3. Fare Details
4. Available Routes
5. Cancellation Policy
6. Customer Support
```

### Step 3: Select "Book Ticket"

Type:

```text
1
```

### Step 4: Choose Your Route

Example:

```text
1. Chennai → Madurai
2. Chennai → Coimbatore
3. Chennai → Trichy
```

Select the route number.

### Step 5: Enter Passenger Details

The chatbot asks for:

- Passenger Name
- Age
- Gender
- Mobile Number

### Step 6: Select Your Seat

Enter the preferred seat number.

Example:

```text
C1
```

### Step 7: Booking Confirmation

The chatbot displays the booking details.

Example:

```text
Booking Confirmed

Passenger : Ramya
Route      : Chennai → Madurai
Seat       : C1
Status     : Confirmed
```

### Step 8: Continue Using the Chatbot

You can also use the chatbot to:

- Check Bus Timings
- View Fare Details
- View Available Routes
- Read Cancellation Policy
- Contact Customer Support
